Dear Purple Campaign Guide

캠페인 안내

PC 참여 방법

총 4단계
1

게시 버튼 클릭

QR코드를 스캔한 후
오른쪽 하단의 게시 버튼을 클릭해 주세요.

2

칭찬 내용 작성 및 게시

본인의 사번 / 이름을 작성한 후,
칭찬하고 싶은 직원의 팀 / 이름 / 칭찬 내용을 기재하고
게시 버튼을 눌러주세요.

3

작성자 확인 후 완료

본인의 사번 / 이름을 작성한 후 완료 버튼을 누르면 제출 완료!

4

공감되는 칭찬에 좋아요

동료의 따뜻한 칭찬을 읽고
공감되는 게시물에 좋아요를 표시해 주세요! 💜

모바일 참여 방법

총 3단계
1

가운데 하단 + 버튼 클릭

QR코드를 스캔한 후
화면 가운데 하단의 + 버튼을 클릭해 주세요.

2

칭찬 내용 작성 및 게시

본인의 사번 / 이름을 작성한 후,
칭찬하고 싶은 직원의 팀 / 이름 / 칭찬 내용을 기재해 주세요. 오른쪽 상단 게시 버튼을 누르면 제출 완료!

3

공감되는 칭찬에 좋아요

동료의 따뜻한 칭찬을 읽고
공감되는 게시물에 좋아요를 표시해 주세요! 💜
